# 🧮 Terminal Calculator (Python Class Version)

A simple, user-friendly terminal-based calculator written in Python and organized using Object-Oriented Programming (OOP).

This tool allows you to perform basic arithmetic operations — addition, subtraction, multiplication, and division — right from your terminal.

---

## 🚀 Features

- 🧠 Clean OOP structure using a `Calculator` class
- 🔄 Continuous calculation loop with exit option
- 📟 Clear and readable prompts
- 🚫 Handles invalid inputs and division by zero
- 🧼 Cross-platform screen clearing (`Windows`, `Linux`, `Mac`)

---

## 🛠️ Technologies Used

- Python 3.x
- Standard Library only (no external dependencies)
